OAuth client

From the Google Cloud console: APIs & Services → Credentials → Create credentials → OAuth client ID, application type Desktop app. Enable the YouTube Data API v3 first, and add your own Google account under OAuth consent screen → Test users or sign-in is refused.

These go to the worker on this machine and are never written to Firestore.
